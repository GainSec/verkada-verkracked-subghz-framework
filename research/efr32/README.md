# EFR32 behavioral model

This directory contains an independently authored, deterministic model of the
normal framing and peer/session behavior attributed to the BH61 EFR32 radio
controller. It is an offline behavioral model, not a cycle-accurate emulator.

The model accepts only byte arrays supplied by the operator or generated by the
included scripts. It opens no radio, serial, USB, or network interface. The
checked-in corpus is regenerated by `generate_corpus.py` from synthetic
identifiers, then bounded mutations are produced by `mutate.py`.

The public model intentionally excludes firmware-update validation behavior,
debug-access research, memory-corruption behavior, exploit-specific states,
and exact executed-byte evidence. Those omissions do not change the C++
framing/decoder implementation.

Evidence status: the model is **independently reconstructed** from static and
controlled research. Its transitions must not be treated as proof that a
physical BH-series device exhibited the modeled behavior.
